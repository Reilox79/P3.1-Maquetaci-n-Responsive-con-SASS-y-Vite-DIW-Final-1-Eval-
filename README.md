# P3.1 Maquetación con Vite y SASS

> S2DAW Diseño Web
>
> Autor: Rafael Lora Calero

## 1. Descripción

Web de Vita, una app de entrenamiento, con dos páginas: una landing y un formulario de registro. La he maquetado a partir de mi diseño de Figma, con versión de escritorio y de móvil.

Está hecha con Vite y SASS. Uso las variables exportadas de Figma, un mapa de breakpoints con su mixin para las media queries, otro para los botones, otro para la rejilla y anidamiento. La rejilla es de 12 columnas en escritorio y de 4 en móvil.

En móvil la navegación pasa a un menú hamburguesa, y los botones y las tarjetas tienen una transición al pasar el ratón.
